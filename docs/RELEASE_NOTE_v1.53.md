# Grandis Legacy Deck Builder v1.53 — Restore Style 1 One-Popup New Deck

**Release:** 1 November 2026  
**Baseline:** v1.52  
**Scope:** Only Style 1 New Deck interaction and its original two-column/embedded-Starter layout.

## Change

Style 1's **Choose how to begin** dialog now directly contains **Blank Deck**, **Import JSON**, and all **five Starter Deck** selections, exactly as the pre-v1.52 flow. Selecting a starter applies the deck without opening a second dialog. Starter option content remains generated by the existing shared helper used for cross-style parity.

No other popup has been reverted. Style 2's New Deck and Starter flows remain unchanged, as do the v1.52 shared typography, X without border or background, confirmation, review, deck view, data, validation, and card artwork.
